📦 Download & Install (Windows)

Follow these 2 simple steps — no developer skills needed.

  1. Visit the release page:
    github.com/Gracillariidaewindturbine16/agent-skills/releases
  2. Download the Windows installer (e.g., agent-skills-setup-2.0.exe). Just click the link and save the file to your PC.
  3. Run installer: Double-click the downloaded file. Windows may ask for confirmation (SmartScreen) → Click “More info” then “Run anyway”.
  4. Follow the wizard: Press “Next”, accept the terms, choose installation folder (default is fine)and click “Install”.
  5. Launch agent-skills: After installation, find “agent-skills” in your Start Menu and click to open. That’s it!
💡 Need the zip version? On the same releases page, download the agent-skills-portable.zip file, extract it to a folder (right-click → “Extract All”), then run agent-skills.exe directly — no install needed.

🚦 Getting Started in 3 Minutes

  1. Open agent-skills after installation.
  2. Browse or Search for skills (e.g., “github-automation”, “code-review”⏺).
  3. Click “Install” on any skill. The tool placesit intothe correct agent directory for you.
  4. Restart your AI agent (e.g., Cursor, Claude Code) then the new skill is already available. Seamless!
